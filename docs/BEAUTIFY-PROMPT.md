# 任务：把 DSH Office TV 的电视页面改造成「可爱的像素办公室 + 非像素鲸鱼娘」

## 你是谁

你是资深 2D 像素美术 + 前端游戏开发，擅长 Canvas 2D，能把像素场景做出温度和生活感。
你要直接改代码、跑起来、截图验证，不要只给建议。

## 项目是什么

**DeepSeek agent Office**：Mac 上跑一个零依赖 Node bridge，把 DeepSeek Harness（DSH）的
会话状态变成一间"深夜办公室"；Android TV APK 用全屏 WebView 播放 `bridge/web/` 页面，
给小朋友看"AI 小人上班"，长按遥控 OK 可以和鲸鱼娘互动。

先读：`README.md`、`PLAN.md`、`CONTRACT.md`，再看 `assets/screenshot-web-1920.png`（改前）。

## 现状

- 页面：`bridge/web/index.html` + `app.js`（约 100KB 单文件）+ `style.css`。
  **零构建、零依赖、无外链、无网络字体**，全部 Canvas 2D 程序化绘制。
- 设计稿：`#stage` 固定 1920×1080，按窗口等比缩放居中（1280×720 / 4K 都不拉伸）。
- 场景：2 行 × 3 列 = 6 个工位（每个对应一个真实 DSH 会话）；右侧站着鲸鱼娘；
  左上 HUD，底部操作提示条。
- 数据：每 2 秒 `GET /api/state`（见 `CONTRACT.md` 第 3 节）：会话标题、status
  （working/waiting/success/idle/error）、activity、todo、团队。
- 鲸鱼娘：`GET /api/pet` 拿 13 个动作 × 241 帧（412×344 透明 webp，24fps），
  `GET /pet/<clip>/<frame>` 取帧。
- 交互：`window.DshTv.onKey('ok' | 'long_ok' | 'back' | 'up' | 'down' | 'left' | 'right' | 'menu')`；
  短按戳鲸鱼娘、长按开「和鲸鱼娘聊聊」面板、方向键移动观察光标、BACK 分层关闭。
- 语音：面板回答优先播 `GET /api/tts?text=`（edge-tts 中文），失败回退 `DshTvNative.speak(text)`，字幕始终显示。
- 目标设备：小米盒子5（HyperOS，2GB RAM，4K 输出，遥控器），WebView = Chrome 100+。

## 用户的核心诉求（一定要按这个来）

1. 「页面有点儿丑，不如像素风那个可爱。」→ **整页要改成像素风。**
2. 「角色也没有走来走去，只有睡觉。」→ 小人要真的会走动、干活、摸鱼。
3. **用户红框圈出来的部分（鲸鱼娘）不要像素风。** 她是高分辨率 anime 角色，
   要**保持原样、高清、平滑**，不能像素化、不能降采样、不能重绘。
   → 这是有意的"像素世界 + 高清角色"混搭，反而最可爱。红框外的一切（房间、家具、小人、
   灯光、UI 边框、装饰）才是像素风。

## A. 视觉：真正的像素风（红框外）

**像素规格（重要）**：
- 场景像素网格 **4px**（1920 宽 = 480 个像素单位），家具/墙/地板/灯全部对齐网格；
  线条 1 格宽，斜角用楼梯式像素，**关闭抗锯齿**（`ctx.imageSmoothingEnabled = false`）。
- 推荐做法：**先把场景画到 480×270 的离屏 canvas**，再用最近邻放大 4× 到 1920×1080。
  这样像素块大小统一、质感真实，比直接在 1920 上画假像素线更"像素"。
- 调色板控制在 **24~32 色**（低饱和、暖冷对比）；渐变用**棋盘格抖动（dither）**，不要平滑渐变；
  发光用有限几档颜色叠加，不要大面积模糊。
- 字体：中文正文仍用系统字体（保证 3 米外可读、不糊），但字重加粗、加 1px 像素描边；
  UI 边框/图标/装饰才是像素风；数字和英文状态可以用系统等宽字体做出"点阵感"。

**配色**（夜晚、暖光）：
- 夜蓝：`#0b1220` `#152241` `#1e3160`
- 奶油：`#f2e8d5` `#e6d7bb`
- 暖金：`#d9a441` `#f2b94b`
- 青色点缀：`#4aa3b8` `#6fd0e0`
- 鲸鱼娘的蓝发是画面最亮的点，周围压暗。

**像素场景要做出的细节**：
1. 深蓝砖墙（错缝、每块砖 2~3 个像素高光）、木地板（板缝 + 高光边）、大窗 + 月亮 + 城市天际线剪影；
2. 家具：2×3 工位（显示器、键盘、鼠标、马克杯、台灯、椅子、桌垫）、饮水机、书架、绿植、
   挂钟、海报、霓虹灯牌 `DSH`、睡着的猫、鱼缸；
3. 光影：台灯暖光池、窗外月光（冷）、显示器冷光（勾边）、地板反光、墙角暗部；
   灯的"光锥"用像素抖动做，不要模糊渐变；
4. 氛围：飘浮尘点（1px 像素点）、窗外雨丝/雪、远景鲸鱼剪影缓慢游过；
5. 生活感：绿植摆动、钟摆、饮水机气泡、咖啡杯热气（3~4 个像素块上升）、猫尾巴轻摆；
6. 工位铭牌：像素小铭牌（1px 深色描边 + 2px 内高光 + 小三角指向小人），层级 标题>状态>步数，
   working 时铭牌有呼吸光；空工位显示"空工位"；
7. HUD/底部提示条：像素边框 + 点阵图标，别像调试面板。

## B. 鲸鱼娘：保持非像素，并让她融入像素场景

- **不要**对她用 `image-rendering: pixelated`，不要降采样、不要重绘、不要调色板量化；
  她的 canvas 层保持 `imageSmoothingEnabled = true`，平滑插值。
- 素材帧有大量透明边距：**按人物实际内容 bbox 对齐**脚下平台，否则会"悬空"。
- 尺寸：约 320~380px 高（相对像素小人 40~60px），大小反差是有意的，不要把她缩成像素小人。
- 让她"站在这个世界里"，而不是"贴在图上"：
  - 脚下椭圆接触阴影（像素抖动边缘）+ 平台水波光圈（像素波纹）；
  - 背后一圈暖色 rim light（像素抖动），与聚光灯方向一致；
  - 呼吸微动（1.0→1.015，2~3 秒周期）；偶尔用 clip 切换眨眼；
  - 气泡改像素对话框（2px 描边 + 小尾巴 + 打字机），别用大圆角毛玻璃。
- 关键验收：截图第一眼能看出"像素房间 + 一个高清小鲸鱼娘"的混搭是**故意的、可爱的**，不是 bug。

## C. 行为：让像素小人「活」起来

按 `/api/state` 的 status 驱动每个工位小人的状态机：

| 状态 | 行为（要有可见动作） |
|---|---|
| `working` | 坐在工位敲键盘（2 帧打字循环 + 屏幕代码滚动 + 头顶小齿轮） |
| `thinking` | 站着托腮看屏幕，头顶思考气泡（`…`） |
| `waiting` | 起身张望，或走到饮水机/窗边等，10~20 秒回工位 |
| `success` | 举手蹦一下（1.5 秒）+ 屏幕闪绿光，然后回工位 |
| `idle` | **随机**：走动、去咖啡机、看窗外、摸猫、打瞌睡（睡觉只能占 idle 的一部分时间） |
| `error` | 快速左右抖动 0.8 秒 + 红色感叹号气泡，然后垂头站着 |

细则：
- 32×32 像素格子 BFS/A* 寻路，不能穿墙/穿桌/互相重叠；
- 小人用**像素 sprite**（16×24 或 24×32，4~6 色），2 帧 walk 循环，带地面阴影和 ±1px 浮动；
- 每个小人给性格参数：速度 40~70px/s、停留 3~10 秒、偏好地点（咖啡机/窗边/书柜）；
- **同一时刻最多 4 个小人在走动**，避免满屏乱窜；
- 空工位显示"空工位"铭牌（可以让猫睡在上面）；
- 关键验收：**随便截 10 秒，至少能看到一次走动或交互**。

## D. 不能破坏的东西（硬约束）

1. 接口：`/api/state`、`/api/pet`、`/api/chat`、`/api/tts`、`window.DshTv.onKey` 的动作集合、
   `DshTvNative` 方法、`onVoiceResult`。**不要改 `bridge/*.mjs`**。
2. 现有交互：短按戳、长按开面板、方向键观察光标、BACK 分层关闭、断线等待画面 + 自动重连、
   `?mock=1`（离线演示）、`?panel=1`（截面板态）、`?cursor=N` 调试参数。
3. 性能（2GB 盒子）：30fps 上限；像素场景画到 480×270 离屏 canvas 再最近邻放大（只画一次静态层）；
   鲸鱼娘帧环形缓冲 ≤24 帧 × LRU 2 clip；不要每帧 `shadowBlur`/`filter`。
4. 台词字符串尽量别改（已按现有文案预生成 TTS 缓存）；必须改时保持语气一致。
5. 不要引入任何外部依赖、CDN、字体文件、图片素材；除鲸鱼娘帧外，所有美术用 Canvas 程序化绘制。
6. 中文在 1280×720 下 3 米外要能读；不要文字溢出/换行炸裂。
