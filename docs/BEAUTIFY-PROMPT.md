# 任务：把 DSH Office TV 的电视页面升级成「精致的深夜插画办公室」

## 你是谁

你是资深 2D 插画师 + 前端动效开发，擅长用 Canvas 2D 手搓「低成本但高级」的插画场景，
懂光影、材质、构图，也懂怎么让角色"活"起来。你要直接改代码、跑起来、截图验证，不要只给建议。

## 项目是什么

**DeepSeek agent Office**：Mac 上跑一个零依赖 Node bridge，把 DeepSeek Harness（DSH）的
会话状态变成一间"深夜办公室"；Android TV APK 用全屏 WebView 播放 `bridge/web/` 页面，
给小朋友看"AI 小人上班"，长按遥控 OK 可以和鲸鱼娘互动。

先读：`README.md`、`PLAN.md`、`CONTRACT.md`，再动手。

## 现在的实现

- 页面：`bridge/web/index.html` + `app.js`（约 100KB 单文件）+ `style.css`。
  **零构建、零依赖、无外链、无网络字体**，全部 Canvas 2D 程序化绘制（渐变/形状/噪点）。
- 设计稿：`#stage` 固定 1920×1080，按窗口等比缩放居中（1280×720 / 4K 都不拉伸）。
- 场景：2 行 × 3 列 = 6 个工位（每个对应一个真实 DSH 会话）；右侧站着鲸鱼娘；
  左上 HUD，底部操作提示条。
- 数据：每 2 秒 `GET /api/state`（见 `CONTRACT.md` 第 3 节）：会话标题、status
  （working/waiting/success/idle/error）、activity、todo、团队。
- 鲸鱼娘：`GET /api/pet` 拿 13 个动作 × 241 帧（412×344 透明 webp，24fps），
  `GET /pet/<clip>/<frame>` 取帧。**这是全页唯一的位图素材**，必须继续用，不要重绘/替换形象。
- 交互：`window.DshTv.onKey('ok' | 'long_ok' | 'back' | 'up' | 'down' | 'left' | 'right' | 'menu')`；
  短按戳鲸鱼娘、长按开「和鲸鱼娘聊聊」面板、方向键移动观察光标、BACK 分层关闭。
- 语音：面板回答优先播 `GET /api/tts?text=`（edge-tts 中文），失败回退 `DshTvNative.speak(text)`，字幕始终显示。
- 目标设备：小米盒子5（HyperOS，2GB RAM，4K 输出，遥控器），WebView = Chrome 100+。

## 用户的抱怨（原话）

1. 「页面有点儿丑，不如像素风那个可爱。」——但**看了现在的截图后决定：不要像素风**，
   就按现在这种"深夜插画"的方向做好看（见 `assets/screenshot-web-1920.png`）。
2. 「角色也没有走来走去，只有睡觉。」

## A. 视觉：在现有"深夜插画"方向上升级（明确不要像素风）

**风格锚点**（保持并强化，不要换赛道）：
- 深夜、暖光、柔和插画；深蓝砖墙 + 木地板 + 大窗月光 + 聚光灯，鲸鱼娘是画面最亮的点。
- 用户圈出来的红框是**鲸鱼娘素材区域**：她必须是画面主角，但现在像"贴上去的"，
  要和场景有光影/材质上的融合（见下面第 5 条）。

**配色**（低饱和、暖冷对比）：
- 夜蓝：`#0b1220` `#152241` `#1e3160`
- 奶油：`#f2e8d5` `#e6d7bb`
- 暖金：`#d9a441` `#f2b94b`
- 青色点缀：`#4aa3b8` `#6fd0e0`
- 鲸鱼娘的蓝发是"最亮的一块"，周围压暗，让她跳出来。

**具体升级方向**：
1. **统一插画语言**：圆角柔和、线条粗细一致、不要硬边网格/像素化/8-bit 抖动；
   家具用"圆角矩形 + 顶部高光 + 底部接触阴影"三件套，看起来是一个画师画的。
2. **光影分层**（重点）：主光（窗外月光，冷）、辅光（台灯/聚光灯，暖）、边缘光（显示器冷光勾边）、
   接触阴影（每个物体与地面/桌面的接缝处必须有）。光要"有体积"：现在那道聚光灯是块死三角，
   要改成上窄下宽、边缘柔化、带尘埃的锥形光柱。
3. **材质与细节**：木地板纹理（细线 + 高光缝）、砖墙错缝、布艺沙发/椅背、玻璃窗反光、
   金属饮水机高光、绿植叶片层次、桌上咖啡杯热气、书架上的书脊、挂钟秒针、睡着的猫。
4. **构图与景深**：前景（桌沿/植物/猫）、中景（工位/小人）、背景（墙/窗/城市天际线）；
   远处元素降低对比度和饱和度做"空气透视"，近处加轻微暗角，让画面有纵深。
5. **鲸鱼娘的融合（用户红框强调的地方）**：
   - 素材帧有大量透明边距：**按人物实际内容 bbox 对齐**到脚下平台上，别用整帧对齐，否则会"悬空"；
   - 加接触阴影（脚下椭圆软阴影）+ 平台水波光圈 + 背后的暖色轮廓光（rim light）；
   - 给她的气泡做成柔光圆角卡（不是现在的硬卡片），出现/消失有轻微缩放+淡入；
   - 呼吸微动（1.0→1.015 缩放，2~3 秒周期），偶尔眨眼（用 clip 切换，不要 p 图）；
   - 平台做成"水洼/光池"：波纹扩散 + 她脚下的倒影（低透明度翻转剪影即可）。
6. **工位铭牌重做**：柔光卡片（毛玻璃感用半透明+描边模拟，不要大面积 blur），
   信息层级：**标题 > 状态 > 步数**；working 时有一圈呼吸光；空工位显示"空工位"。
7. **HUD 与提示条**：统一成"晚间电台"气质——细字距、小图标、下划线高亮，别像调试面板。

**避免**：像素化、硬边网格、8-bit 色块、大面积 CSS blur/filter、堆渐变发光、扁平 PPT 感、
正文小于 20px、三种以上字体风格混用。

## B. 行为：让小人「活」起来（和风格无关，必须做）

按 `/api/state` 的 status 驱动每个工位小人的状态机：

| 状态 | 行为（要有可见动作） |
|---|---|
| `working` | 坐在工位敲键盘（2~3 帧打字循环 + 屏幕代码滚动 + 头顶小齿轮/进度点） |
| `thinking` | 站着托腮看屏幕，头顶思考气泡（`…`） |
| `waiting` | 起身张望，或走到饮水机/窗边等，10~20 秒回工位 |
| `success` | 举手蹦一下（1.5 秒）+ 屏幕闪绿光，然后回工位 |
| `idle` | **随机**：走动、去咖啡机、看窗外、摸猫、打瞌睡（睡觉只能占 idle 的一部分时间） |
| `error` | 快速左右抖动 0.8 秒 + 红色感叹号气泡，然后垂头站着 |

行为细则：
- 办公室用 **32×32 像素格子**做简单寻路（BFS/A* 都行），不能穿墙/穿桌/互相重叠；
- 走动用 2~3 帧 walk 循环（Canvas 画的简化 chibi 小人：圆头 + 小身体 + 两点眼睛 + 细手脚），
  带地面阴影和 ±1px 上下浮动；**不要像素小人**，要圆润、和鲸鱼娘同一套"可爱语言"；
- 每个小人给性格参数：速度 40~70px/s、停留 3~10 秒、偏好地点（咖啡机/窗边/书柜），
  看起来自然随机、但不乱；
- **同一时刻最多 4 个小人在走动**；
- 空工位显示"空工位"铭牌（可以让猫睡在上面）；
- 关键验收：**随便截 10 秒，至少能看到一次走动或交互**。

## C. 不能破坏的东西（硬约束）

1. 接口：`/api/state`、`/api/pet`、`/api/chat`、`/api/tts`、`window.DshTv.onKey` 的动作集合、
   `DshTvNative` 方法、`onVoiceResult`。**不要改 `bridge/*.mjs`**。
2. 现有交互：短按戳、长按开面板、方向键观察光标、BACK 分层关闭、断线等待画面 + 自动重连、
   `?mock=1`（离线演示）、`?panel=1`（截面板态）、`?cursor=N` 调试参数。
3. 性能预算（2GB 盒子）：30fps 上限；静态背景只画一次到离屏 canvas；鲸鱼娘帧环形缓冲
   ≤24 帧 × LRU 2 clip；不要每帧 `shadowBlur`/`filter`；文字用系统字体。
4. 台词字符串尽量别改（已按现有文案预生成 TTS 缓存）；必须改时保持语气一致。
5. **不要引入任何外部依赖、CDN、字体文件、图片素材**：除了鲸鱼娘的帧，所有新美术都用
   Canvas 程序化绘制（渐变、路径、噪点纹理都可以）。
6. 中文在 1280×720 下 3 米外要能读；不要出现文字溢出/换行炸裂。

```bash
open "http://127.0.0.1:8765/tv?mock=1" # 无 DSH 状态时的假数据演示
```

- 帧率自测：平均 ≥28fps；
